# Fonts for rendered documents

All under the SIL Open Font License 1.1 (see the OFL files), which allows bundling and embedding.

- `GoogleSansText-*.ttf`: Google Sans Text, static Latin builds from the googlesans v14.000 release (`build/GoogleSans/android/static`).
- `Merriweather-Regular.ttf`, `Merriweather-Bold.ttf`: Merriweather 2.x static Regular and Bold from google/fonts (commit e9263a54, before the variable remaster).

Static files, not variable fonts: LibreOffice can export variable fonts to PDF in a form text extraction cannot read.
